Necesito desarrollar un prototipo completo funcional para probar hoy de un sistema profesional de competencias de patin artistico.

Debe ser una app web local, simple de ejecutar, sin base SQL por ahora, usando React + Vite + localStorage.

Objetivo: probar todos los flujos principales.

Debe incluir:
- Torneos
- Categorias
- Clubes con logo/escudo
- Tecnicas/maestras con foto
- Patinadoras con foto, edad, club, tecnica y musica
- Jueces
- Pantalla operador
- Pantalla jueces
- Pantalla publica/LED
- Reproduccion de musica
- Silbato
- Receso con tiempo configurable
- Carga de puntajes por varios jueces
- Modo puntaje consensuado
- Doble confirmacion de puntaje
- Bonus
- Observaciones privadas de jueces
- Ranking por categoria
- Ranking por clubes por cantidad de 1, 2, 3 puestos, podios e incentivos
- Impresion de acta por categoria con firma de jueces
- Impresion de premiacion final
- Logs basicos
- Visual moderno, oscuro, tactil, muy intuitivo, con botones grandes

Crear la estructura completa del proyecto y dejarlo funcionando con:
npm install
npm run dev

Prioridad:
1. Que funcione hoy.
2. Que sea facil de usar.
3. Que tenga datos demo.
4. Que permita probar todo el flujo de competencia.
